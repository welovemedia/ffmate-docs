# How to Reach Out

Questions and feedback about FFmate go to the FFmate Discord server or the FFmate GitHub repository.

## Join the FFmate Community on Discord

The FFmate team and other FFmate users talk on the [FFmate Discord server](https://discord.gg/NzfeHn37jT). Ask questions there, share ideas and hear about new features and releases.

## Feature Requests and Issues

To request a feature or report a problem, open an issue in the [FFmate GitHub repository](https://github.com/welovemedia/ffmate). Code changes are welcome as pull requests.
